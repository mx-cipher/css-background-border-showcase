# CSS Background and Border Showcase 

A sleek, modern, and interactive **Profile Card UI** created specifically to practice and master advanced **CSS Backgrounds & Borders**. This project showcases how dark themes, multi-color neon borders, and complex gradients can work together to build a stunning visual layout.

## Key Learning Focus
The main goal of this project was to learn and implement:
- **Advanced Gradients:** Using combinations of `linear-gradient` for the page background and `radial-gradient` for the card structure.
- **Complex Borders & Outlines:** Implementing custom double-layered borders using standard CSS `border` properties combined with neon `outline` and `outline-offset`.
- **Interactive UI Elements:** Designing smooth transitions (`transition`) and responsive shadow scales (`box-shadow`) on interactive hover buttons.

##  Tech Stack Used
- **HTML5:** Structured semantic markup for the profile component.
- **CSS3:** Advanced background properties, multi-color layout styling, box-shadows, and transitions.

## Features Shown in Code
- **Background Fusion:** A stunning dark background mixed with subtle red and cyan tones.
- **Neon Cyan Accent:** Vibrant glowing effects tailored perfectly around the profile avatar and follow button.
- **Glass & Depth Design:** Soft border opacity mixed with heavy dark drop shadows to give the layout high contrast and visual hierarchy.
